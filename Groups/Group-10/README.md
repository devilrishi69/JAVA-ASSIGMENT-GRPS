# RentInstead — Student Rental Marketplace

> **Access Instead Of Ownership**

RentInstead is a student-focused, student-to-student rental marketplace presented as an **Advanced Java Programming** project at **Guru Ghasidas Vishwavidyalaya, Bilaspur (CG)**. The platform is designed to help students rent useful items for short-term needs instead of purchasing them, while allowing item owners to earn from products they do not regularly use.

## Project Overview

Students may need items for a limited period, making a purchase unnecessarily expensive. At the same time, other students may already own items that remain unused. RentInstead proposes a centralized platform where students can:

- List items available for rental.
- Search and browse available items.
- Select rental dates.
- Send rental requests.
- Approve or reject requests as item owners.
- Manage bookings and rentals.
- Return rented items.
- Give and receive ratings/reviews.

The platform also includes administrative management for users, listings, categories, bookings, reports, and statistics.

## Problem Statement

The presentation identifies the following problems faced by students:

- Students often need expensive items only for a short period.
- Buying such items can be costly.
- Many students already own items that remain unused.
- Finding trustworthy rental options within a college community can be difficult.
- Rental transactions are often handled informally through friends or groups.
- There is no centralized platform for managing listings, requests, and rental records.

## Objectives

The project aims to:

1. Provide an easy platform for student rentals.

3. Help students earn from unused items.

## System Workflow

The proposed workflow is:

```text
Register / Login
      ↓
Select User Role
      ↓
Student / Owner / Admin
      ↓
Browse or Manage Items
      ↓
Rental Request
      ↓
Owner Receives Request
      ↓
Approval
      ↓
Booking
      ↓
Rental
      ↓
Return
      ↓
Review
```

For a student renter, the core rental process is:

```text
Student needs an item
        ↓
Searches RentInstead
        ↓
Finds available item
        ↓
Selects rental dates
        ↓
Sends request
        ↓
Owner approves
        ↓
Student uses item
        ↓
Item is returned
```

## Conclusion

RentInstead presents a digital solution for student-to-student rentals. It is intended to help students access useful products without purchasing them while giving item owners an opportunity to earn from products they do not use regularly.

The proposed platform demonstrates role-based access, item listings, rental requests, bookings, reviews, and administrative management.
