## 📌 About the Project

This project demonstrates how basic animation can be created using Java graphics.

The animation follows a simple sequence:

**Text Animation → Ball Movement → Color Change → Ball Growth**

The project uses Java Swing, AWT Graphics, and a Timer to repeatedly update and redraw the screen.

---

## 🎯 What the Animation Does

When the program starts:

1. A black window opens.
2. The text **"BALL ANIMATION"** appears letter by letter.
3. A blue ball starts near point **A**.
4. The ball moves from **A to B**.
5. The ball gradually changes from **blue to red**.
6. The ball increases in size.
7. The timer stops when the ball reaches its final size.

## 🔄 Animation Steps

The `step` variable controls the order of the animation:

| Step | Action |
|------|--------|
| `0` | Display text letter by letter |
| `1` | Move the ball from A to B |
| `2` | Change ball color from blue to red |
| `3` | Increase the ball size |

This makes the different parts of the animation happen in sequence.

## 👨‍💻 Team Contribution

### Member 1 — Text Animation

Responsible for displaying the project title letter by letter using:

```java
showName(Graphics g)
```

### Member 2 — Ball Movement

Responsible for moving the ball horizontally from A to B using the `x` position:

```java
moveBall()
```

### Member 3 — Color Change

Responsible for changing the ball color gradually from blue toward red:

```java
changeColor()
```

### Member 4 — Ball Growth

Responsible for increasing the ball size and stopping the timer when the final size is reached:

```java
changeSize()
```
